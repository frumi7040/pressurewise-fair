# Hydraulic Model Directory

## Purpose

This directory is reserved for the hydraulic network models and configuration files used by PressureWise-Fair.

The proposed system uses EPANET 2.2 through WNTR to investigate pressure distribution, customer demand satisfaction, and pressure-driven leakage.

## Planned Contents

Future model assets may include:

- EPANET input files (`.inp`).
- Network configuration files.
- Demand pattern definitions.
- Leakage emitter configurations.
- PRV configuration and candidate settings.
- Scenario-specific model inputs.

## Model Requirements

Each model should document:

1. Network topology and input sources.
2. Units and hydraulic parameters.
3. Demand assumptions.
4. Leakage locations and emitter parameters.
5. PRV placement and operating assumptions.
6. Simulation duration and time steps.
7. Software versions.

## Important

No calibrated or validated hydraulic network model is currently claimed by this directory.

Only appropriately sourced, documented, and permitted model files should be added.

**All simulation results must be identified as modeled results, not field measurements.**
