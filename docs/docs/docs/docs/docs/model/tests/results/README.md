# Results Directory

## Purpose

This directory is reserved for the outputs generated by future PressureWise-Fair simulations and optimization experiments.

## Planned Results

Future outputs may include:

- Baseline hydraulic simulation results.
- Candidate schedule evaluation records.
- Simulated leakage volumes.
- Demand Satisfaction Ratio calculations.
- Lower-tail service equity indicators.
- Critical-junction pressure checks.
- Pareto analysis data.
- Validation logs and experiment summaries.

## Data Requirements

Each result set should identify:

1. Scenario identifier.
2. Network model version.
3. Software versions.
4. Model parameters.
5. PRV schedule.
6. Simulation status.
7. Objective values and units.
8. Validation status.

## Reporting Rules

- Simulated outputs must be labeled as simulated.
- Field measurements must be identified separately.
- Failed simulations must not be silently excluded.
- Missing results must not be replaced with invented values.
- Every published graph must be traceable to its underlying data.

## Current Status

No verified hydraulic simulation or optimization results are currently claimed in this directory.
