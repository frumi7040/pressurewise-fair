# Security Policy

## Supported Versions

PressureWise-Fair is a research prototype and does not currently publish
versioned releases or provide a formal security-update support schedule.
Security fixes, when applicable, are made against the current `main` branch.

| Version | Supported |
| --- | --- |
| Current `main` branch | Best-effort review and fixes |
| Older commits and untagged snapshots | No security-update guarantee |

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion,
or pull request.

If GitHub's **Private vulnerability reporting** feature is enabled for this
repository, use the repository's Security tab to submit a private report.
Otherwise, contact the repository maintainer privately through their GitHub
profile and include a concise description, affected files or commits, impact,
and reproduction steps. Do not include live credentials in the report; use
redacted examples.

There is currently no guaranteed response or remediation service-level
agreement. The maintainer will acknowledge reports when reasonably possible,
assess their validity and impact, and coordinate any necessary fix or
disclosure with the reporter.

## Scope and Safety

PressureWise-Fair is a simulation and research prototype, not an operational
water-network controller. Do not test against live water infrastructure or
systems you do not own or have explicit permission to assess.
